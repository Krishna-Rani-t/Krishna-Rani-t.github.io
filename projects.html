University and personal projects in machine learning, explainability and retrieval.

  • FedLIME: federated learning with LIME

    University project

    Federated learning keeps data on each client, but that makes it hard to explain what the shared model learned. FedLIME produces explanations without moving raw data or detailed explanations off the clients.

    • Trains a shared neural network with Flower (FedAvg) across 3–10 simulated clients, using random and demographic-based data splits.
    • Generates LIME explanations locally on each client and shares only summaries protected with Gaussian local differential privacy.
    • Evaluated on Adult Income, Bank Marketing and Law School. Federated explanations reached up to 0.96 similarity to the centralised baseline and matched or exceeded its fidelity (up to 0.53 vs. 0.30 R²).

    Python, Flower, LIME, differential privacy

  • RNA-to-protein prediction

    AI in biomedicine, university project

    Predicts protein expression from single-cell RNA data, using the Kaggle Open Problems – Multimodal Single-Cell Integration dataset.

    • Trained and compared Ridge Regression, Random Forest, a fully connected neural network and an autoencoder as baselines.
    • Built a prediction pipeline on the pretrained scGPT single-cell foundation model, adding a neural network head to predict protein levels.

    Python, PyTorch, scGPT, single-cell multiomics

  • Retrieval-augmented generation with local models

    Personal project

    A small RAG chatbot that runs entirely on local models through Ollama. It embeds a document collection with BGE, retrieves the closest chunks by cosine similarity, and answers with Llama 3.2 1B Instruct using only the retrieved context, streaming the response.

    Python, Ollama, BGE embeddings, Llama 3.2
